# 🌒 LOST EDEN · Discord Bot

> **We don't return. We rebuild.**

Discord-бот для сервера **LOST EDEN · RIMAY**, написанный на Python с использованием `discord.py`.

Проект развивается как собственная система сервера: профиль участника, прогресс, экономика, достижения, ритуалы, игровые активности, верификация и административные инструменты собраны в одном визуальном и смысловом стиле LOST EDEN.

---

## About

**LOST EDEN Bot** создаётся специально для Discord-сервера **LOST EDEN · RIMAY**.

Это не универсальный бот-комбайн. Его задача — быть частью самого сервера: встречать новых участников, хранить их прогресс, показывать путь внутри Сада, поддерживать игровые активности и связывать между собой уровни, награды, роли и экономику.

Основные принципы проекта:

- slash-команды на русском языке;
- интерактивные интерфейсы через `discord.ui`;
- единый стиль embed-сообщений;
- собственные графические карточки через Pillow;
- постоянное хранение статистики;
- разделение Discord-интерфейса, бизнес-логики и базы данных;
- минимум лишнего функционала;
- механики, которые поддерживают атмосферу **Lost Eden / Paradise**.

Главная идея проекта:

> **We don't return. We rebuild.**

## Что уже реализовано

### Профиль участника

Команда `/профиль` формирует полноценную графическую карточку участника.

На карточке используются реальные данные сервера:

- аватар и отображаемое имя;
- Discord username;
- уровень;
- место в рейтинге;
- общий XP;
- XP до следующего уровня;
- баланс;
- количество EDEN CASES;
- статус верификации;
- текущая юбилейная роль;
- сообщения;
- время в голосовых каналах;
- количество открытых достижений;
- количество DUEL;
- количество CLOSE.

Под карточкой дополнительно отображается статистика EVENT, победы и winrate в DUEL/CLOSE.

Для более подробной статистики используется `/прогресс`.

---

### Прогресс и уровни

Бот автоматически собирает активность участников и переводит её в общую систему прогресса.

Учитываются:

- сообщения;
- время в голосовых каналах;
- XP;
- уровень;
- место в рейтинге;
- участия в EVENT;
- подтверждённые DUEL;
- подтверждённые CLOSE;
- достижения;
- ежедневный ритуал.

Уровень рассчитывается из накопленного XP. При повышении уровня участник получает **EDEN CASE**, в том числе если за одно начисление было получено сразу несколько уровней.

Команда `/рейтинг` показывает leaderboard участников сервера.

---

### EDEN CASES

`/кейсы` открывает личное хранилище кейсов участника.

Кейсы связаны с progression-системой и выдаются за повышение уровня. Интерфейс показывает:

- текущее количество кейсов;
- уровень;
- сколько XP осталось до следующего уровня и следующего кейса.

Открытие кейса происходит через интерактивную кнопку.

---

### Экономика

Внутренняя валюта проекта называется **Средства** и обозначается символом `🍎`.

Экономика используется в нескольких системах одновременно:

- награды за активности;
- достижения;
- ежедневный ритуал;
- EDEN CASES;
- казино;
- административные начисления и списания.

Изменения баланса проходят через отдельный слой экономики, чтобы игровые механики не работали напрямую с таблицей статистики.

---

### Достижения

Команда `/достижения` показывает текущий прогресс по достижениям.

Для каждого достижения отображаются условие, текущий прогресс и награда. Поддерживаются награды в Средствах и EDEN CASES.

Достижения могут зависеть от активности участника, голосового времени, количества матчей, побед и других метрик.

Открытые достижения также отображаются в `/профиль` и `/прогресс`.

---

### Ежедневный ритуал

Команда `/ритуал` доступна один раз в 24 часа.

Ритуал выдаёт случайную награду системы и хранит время следующего доступного использования. Состояние ритуала также видно в `/прогресс`.

## Система активностей

В проекте есть общий фундамент для трёх типов активности:

```text
EVENT
DUEL
CLOSE
```

Они используют общие сущности активности, участников, статусов и наград, но имеют собственную игровую логику.

### EVENT

Администратор или пользователь с правом управления сервером может создать серверный ивент, задать описание, максимальное количество участников и награды.

Участники записываются через кнопки. EVENT проходит состояния создания, запуска, завершения или отмены.

После завершения бот может автоматически начислить участникам XP, Средства и EDEN CASES. Дополнительную награду можно выдать отдельно.

Основные команды:

```text
/создать-ивент
/запустить-ивент
/завершить-ивент
/отменить-ивент
/награда-ивента
/ивенты
```

---

### DUEL

DUEL — персональный матч между двумя участниками.

Один пользователь вызывает другого через `/дуэль`. Второй игрок принимает или отклоняет вызов через интерактивный интерфейс.

После матча один из участников предлагает результат, а второй должен его подтвердить. Только подтверждённый результат попадает в статистику профиля и прогресса.

Основные команды:

```text
/дуэль
/результат-дуэли
/отменить-дуэль
/дуэли
```

Открытые DUEL и ожидающие подтверждения результаты восстанавливают свои интерактивные кнопки после перезапуска бота.

---

### CLOSE

CLOSE — командная соревновательная активность.

Поддерживаются размеры:

```text
2×2
3×3
4×4
5×5
```

Формирование команд может проходить двумя способами:

```text
случайное распределение
выбор игроков капитанами
```

При капитанском режиме капитаны выбираются случайно, первый пик также определяется случайно, после чего капитаны по очереди набирают игроков.

Основные команды:

```text
/создать-клоз
/запустить-клоз
/выбрать-игрока
/результат-клоза
/подтвердить-клоз
/клозы
```

Результат записывается в статистику только после подтверждения. Победители получают бонус, а проигравшие всё равно получают небольшую награду за участие.

## Верификация

Верификация построена вокруг одной Discord-роли.

ID роли задаётся в `.env`:

```env
VERIFIED_ROLE_ID=123456789012345678
```

Discord-роль является источником истины. Если она есть у участника, бот считает его верифицированным.

### Панель верификации

Администратор один раз вызывает в нужном канале:

```text
/панель-верификации
```

Бот публикует постоянную панель с кнопкой **«Пройти верификацию»**.

После нажатия участнику автоматически выдаётся роль верификации. Кнопка является persistent view и продолжает работать после перезапуска бота.

Дополнительно существуют ручные админ-команды:

```text
/верифицировать
/снять-верификацию
```

Для корректной работы роль бота должна находиться **выше роли верификации**, а у бота должно быть право `Управлять ролями`.

Типичная схема прав сервера:

```text
невeрифицированный участник
        ↓
видит правила + канал верификации
        ↓
нажимает кнопку
        ↓
получает роль Верифицирован
        ↓
открываются основные категории сервера
```

Статус верификации отображается на карточке профиля.

## Юбилейные роли

Проект поддерживает milestone-роли, которые зависят от уровня участника.

Система умеет определять текущую и следующую юбилейную роль, показывать их в `/прогресс` и синхронизировать Discord-роли с фактическим уровнем пользователя.

Таблица milestone-уровней настраивается в `config/roles.py`.

## Архитектура

Проект разделён на слои:

```text
Discord
  ↓
cogs/
  ↓
views/
  ↓
services/
  ↓
database/
```

`cogs/` отвечают за slash-команды и события Discord.

`views/` содержат интерактивные кнопки, меню и состояния интерфейсов.

`services/` содержат игровую и прикладную логику: progression, активности, достижения, награды, роли, верификацию, DUEL и CLOSE.

`database/` отвечает за SQLite и запросы к данным.

`utils/` содержит генераторы изображений, форматирование, leveling и общие вспомогательные функции.

### SQLite + aiosqlite

База используется для постоянного хранения статистики, экономики, progression и игровых активностей. Данные не исчезают после перезапуска бота.

### discord.ui

Используется для постоянных и временных интерактивных интерфейсов: верификация, активности, кейсы, казино, навигация и другие кнопочные сценарии.

## Установка

Клонирование проекта:

```bash
git clone https://github.com/smalltalk-eater/dark-dis-bot.git
cd dark-dis-bot
git switch smalltalk
```

Создание виртуального окружения:

```bash
python -m venv .venv
```

Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Создай `.env` на основе `.env_example`:

```env
DIS_TOKEN=YOUR_DIS_TOKEN
GUILD_ID=YOUR_GUILD_ID
WELCOME_CHANNEL_ID=YOUR_WELCOME_CHANNEL_ID
VERIFIED_ROLE_ID=YOUR_VERIFIED_ROLE_ID
```

Запуск:

```bash
python bot.py
```

При старте бот:

1. загружает переменные окружения;
2. инициализирует базу;
3. подключает Cogs;
4. восстанавливает persistent Views;
5. синхронизирует slash-команды для сервера;
6. подключается к Discord Gateway.

## Discord permissions

Для полноценной работы боту могут понадобиться:

```text
Просмотр каналов
Отправка сообщений
Встраивание ссылок
Прикрепление файлов
Чтение истории сообщений
Использование внешних эмодзи
Управление ролями
```

Для динамического баннера нужны соответствующие права управления сервером и поддержка баннера самим сервером.

Для верификации особенно важно:

```text
роль LOST EDEN BOT
        ↑
роль Верифицирован
```

Бот не может выдать роль, находящуюся выше его собственной роли.
